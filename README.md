# Evolve Landing Site

Static landing page for Evolve.

## Local preview

Open `index.html` directly, or serve the folder with any static host.

## Creator portal

The static `/creators/` path redirects to `https://go.theevolve.app/creators/`,
where the creator application, login, and dashboard are hosted on Cloudflare
Pages.

## Deploy

This folder is ready for GitHub Pages, Netlify, Cloudflare Pages, or any basic static hosting provider.
